## 拆解结论（实体-视图分析先行）

1. **中台十视图不拆页**：知识运营中台为单 Web 应用+左侧一级导航（十视图五组，PRD §5.10 NAV 定稿）；十视图为同一应用内的导航视图而非独立页面，且用户自制 v3 原型（单 HTML）已收编为权威原型——按原型形态登记为 **1 个页面条目**，视图明细列入功能范围描述。
2. **C 端零页面**：帮助中心/在线聊天 bot/邮件工单/客服工作台全部为 Zendesk 生态承担（外部承接，非本次交付）——本清单不为 Zendesk 界面造页面，仅在 retired 表登记承接关系。
3. **登录与首次改密不单列**：RBAC 真实账号体系（建议值 邮箱+密码邀请制、首次登录强制改密，PRD §0.5）为中台门面配套，归属 PAGE-F09-01 交付范围，不单列页面 ID。
4. **异常/隐性状态全部为视图内状态**：同步失败/阻断、翻译失败/待重新校验、drift 报警、空批次/失败批次、AI 摘要未生成待重建、并发冲突、越权禁用、账号禁用（PRD §7.1 中台状态矩阵）均不出独立页面，逐项归入 PAGE-F09-01 功能范围。
5. **无界面功能如实登记**：Zendesk 配置迁移（Guide 结构映射/segment 划分/bot 知识源接通/Explore 口径确认）、每日挖掘批次任务、drift 周期检测、同步推送管道均为配置/后台任务——界面承载归对应视图，无界面部分登记于表 3，不造页面。
6. **planned 页面只登记**：后续阶段条目仅记 `planned + 前置依赖 + 与 MVP 关系 + 功能范围`，本轮不出施工任务、不创建文件。
