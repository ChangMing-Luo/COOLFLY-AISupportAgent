## 2. 页面概述

### 2.1 一句话定位

让业务负责人与运营三岗从上线第一周起，按周只读查看智能客服的双口径解决率、拒答率、转人工量、语言分布等核心效果指标，回答"这笔投入是否值得"（US-F06-01）。

### 2.2 存在理由

1. 无看板则解决率/拒答率/转人工量不可见，MVP 完成定义中"效果按周可看"（AC-M-10 / AC-F06-01）无法验收，切采购扳机（严口径连续 2 个月 <45%）无数据判定。
2. 拒答率超预期区间是"知识库改造未到位"信号，且为灰度放量前置条件之一（REQ-F06-02）——没有分层标红呈现，灰度决策失去依据。
3. 转人工量逼近人工容量（3 人团队）时若无预警线可视化与推送联动，业务侧来不及启动容量预案（US-F06-02）。

### 2.3 页面目标（可衡量）

| 目标维度 | 具体指标 |
| :--- | :--- |
| 可用时点 | 灰度第一周即有数据、按周可看（AC-F06-01） |
| 指标完整性 | 双口径解决率、拒答率（分层）、转人工量、语言分布均有数据呈现（AC-F06-01） |
| 数据新鲜度 | 看板数据延迟「建议值 ≤24h · 终稿前确认」（PRD §5.7 边界数值） |
| 口径不污染 | 旧版本无字段流量 100% 归"未知"桶单列，不摊入任何分层（REQ-F06-01） |
| 访问安全 | 无口令访问 100% 被拦截；访问留痕（蓝图 §3/§9） |

### 2.4 不做什么（范围边界）

- **不做**指标口径与目标值的重新定义——口径与目标值唯一落点在 PRD §8.1/§8.2，本页逐项引用呈现，不复制、不另造（R2-裁决 10 同理）。
- **不做**退货归因图表——MVP 为月度手工表登记 🟩（看板化 🟨 依 G4 查证结果），页面仅留说明位，不出图（PRD §5.7 元素表）。
- **不做**任何写操作/配置操作——看板为内部只读，数据面只读埋点聚合视图，不直连业务表写路径（页面清单/蓝图 §7）。
- **不做**账号体系与权限管理界面——访问控制为「建议值 口令（Basic Auth）+ 链接不公开 · 终稿前确认」，无注册/登录/用户管理页（蓝图 §3，requirements 无对应 REQ）。
- **不做**容量预警推送的界面——推送为飞书机器人触达（建议值 · 终稿前确认），本身无界面（页面清单表 3）；本页仅承载预警线在趋势图上的可视化叠加。
- **不做**移动端适配承诺——仅桌面 Web 1280+ 宽（蓝图 §1）。

## 3. 用户与场景

### 3.1 目标用户

| 维度 | 描述 |
| :--- | :--- |
| 角色 | 业务负责人（别名：企业家，间接角色）+ 运营三岗（拍板 2：兼任名单），共约 4 人 |
| 人数 | 单次使用 1 人；全量使用者固定小圈子（内部链接不公开） |
| 技术熟练度 | 中高（日常使用数据报表与飞书办公） |
| 使用设备 | 桌面电脑 / 笔记本（1280+ 宽浏览器） |
| 使用姿势 | 每周例行查看 + 收到预警/背离提示后专项核查 |

### 3.2 核心使用场景

**场景 A：周度效果例查（主场景）**
- 时机：每周固定时间（如周一），或灰度第一周起的任意时点
- 前置：持有内部访问链接与口令；本周埋点数据已聚合（延迟 ≤24h 建议值）
- 动作：输入口令进入 → 浏览双口径解决率趋势（切换 entry_source 分层）→ 查看拒答率三层是否落在预期区间 → 查看转人工量与预警线距离 → 扫读解决时长/满意度/语言分布/沉默放弃率图卡
- 情绪：例行、求准——最关心"数字是否可信、口径是否被污染"

**场景 B：预警/异常核查（兜底场景）**
- 时机：收到飞书容量预警推送后，或看到拒答率标红/三指标背离提示后
- 前置：预警已触发（月转人工绝对量达 G1 实测月处理量 ×80%）或某触发层拒答率超区间
- 动作：进入看板 → 定位转人工量与预警线交叉点 / 标红的拒答触发层 → 结合分层维度判断是"引擎效果"还是"入口效果"问题 → 离开看板启动业务侧预案（复查动作归 PRD §8.3，不在本页执行）
- 情绪：警觉、要快——需要一眼定位异常层与异常周

**场景 C：数据不全时的降级查看（兜底场景）**
- 时机：G1 未产出预警线分母，或客户端埋点延迟回补期间
- 前置：预警线缺分母 / 部分周数据标注"数据回补中"
- 动作：进入看板 → 看到转人工卡降级为绝对量趋势 + 明示"预警线待 G1 回填" → 对延迟周按标注理解数据不完整，不误读为真实下跌
- 情绪：可接受——降级有明示，不被静默缺数误导

### 3.3 用户核心诉求（优先级排序）

1. **可信**：口径不被污染（未知桶单列、双口径分列、灰度结论区分引擎/入口效果）
2. **及时**：灰度第一周就有数、周更、延迟 ≤24h（建议值）
3. **一眼定位异常**：超区间标红、预警线叠加、背离提示，不用自己算
4. **降级不糊弄**：数据回补中/预警线待回填必须明示，不静默缺数

## 4. 信息架构

### 4.1 区域划分

单页自上而下：

1. 顶部页头区（标题 + 数据口径说明位 + 周区间选择）
2. 核心趋势区 · 双口径解决率（含 entry_source 分层切换器）
3. 核心趋势区 · 拒答率分层（三层分列 + 预期区间带）
4. 核心趋势区 · 转人工率与绝对量（含容量预警线叠加）
5. 图卡区（解决时长 / 满意度 / 语言分布 / 沉默放弃率四卡）
6. 退货归因说明位（月度手工表登记，不出图）
7. 页脚（数据延迟说明 / 时区口径说明）

### 4.2 区域内容

**1. 顶部页头区**
- 看板标题（产品名 + "效果看板"）
- 数据更新时间与延迟说明（「建议值 ≤24h · 终稿前确认」）
- 周区间选择器（design-derived: DEC-004——趋势图需指定呈现的周范围，上游未定默认窗口，建议默认最近 12 周，由设计/技术方案定）
- 三指标背离提示条（仅背离触发时出现，见第 7 节）

**2. 双口径解决率趋势区**
- 宽口径 / 严口径两条周粒度趋势（口径引用 PRD §8.2 前两行，不复制定义）
- entry_source 分层切换器：固定入口 / 错误态入口 / 未知（未知桶单列，不摊入分层）
- 交互方式（按钮组/自由输入/预置意图）为次维（REQ-F06-01；枚举唯一落点 PRD §4.2）
- 目标/底线参考线：严口径高频类 60%/45%、宽口径高频类 60%/整体 50%（值引用 PRD §8.2，A-004 假设值 G1 后校准）
- 沉默放弃率联动说明（宽−严差值，详见图卡区）

**3. 拒答率分层区**
- 触发层①检索相关度 / ②引用忠实 / ③硬规则 三条分列折线（层定义引用 PRD §3.3）
- 预期区间带叠加（区间值 `[PRD 定数 · G1 后回填]`）
- 超区间的层视觉标红（AC-F06-02）

**4. 转人工区**
- 转人工率 + 月绝对量数值与趋势
- 容量预警线叠加（= G1 实测月处理量 ×80%，分母 `[PRD 定数 · G1 后回填]`）
- 触线即飞书推送的联动说明（推送无界面，仅此处可视化）
- 降级形态：分母缺失时仅绝对量趋势 + "预警线待 G1 回填"明示（AC-F06-03）

**5. 图卡区（四卡）**
- 自助解决时长卡（目标 ≤10 分钟，口径引用 PRD §8.2）
- 会话满意度卡（趋势参考、不设达标线，口径引用 PRD §8.2）
- 语言分布卡（非英语 >15% 为完整多语言触发器，阈值标注引用 PRD §8.2）
- 沉默放弃率卡（宽−严差值；差值持续扩大 → 口径复查提示，引用 PRD §8.2）

**6. 退货归因说明位**
- 文字说明：月度手工表登记（🟩），看板化（🟨）依 G4 查证结果后评估；不出图表

**7. 页脚**
- 时区口径说明：窗口计算按 UTC，看板按业务时区呈报（REQ-F06-04 / PRD §4.5）
- 访问留痕说明（时间/操作者/动作，蓝图 §9）

## 5. 界面内容

### 5.1 元素清单

> 以下所有出现的具体数值（如 58%、区间上下限）均为**示例值**，真实值来自埋点聚合与 `[PRD 定数 · G1 后回填]`；指标口径逐项引用 PRD §8.1/§8.2，本页不重复定义。

**双口径解决率趋势图**
- 内容：宽/严两口径周粒度折线（如某周 宽 58%、严 46%，示例值）+ 目标/底线参考线
- 数据来源：埋点聚合视图（会话结束/会话重新激活/满意度评分事件，PRD §4.2）
- 显示条件：始终显示；所选分层无数据周显示空档并标注（不画零值假线）

**entry_source 分层切换器**
- 类型：单选切换（全部 / 固定入口 / 错误态入口 / 未知）
- 文案："全部｜固定入口｜错误态入口｜未知"
- 数据来源：会话级 entry_source 属性（枚举唯一落点 PRD §4.2）
- 显示条件：始终显示；"未知"为独立桶，任何情况下不并入前两层

**交互方式次维筛选**
- 类型：次级筛选（按钮组 / 自由输入 / 预置意图）
- 数据来源：消息级 interaction_mode 属性（PRD §4.2；与 entry_source 为两个独立维度，R2-裁决 8）
- 显示条件：始终显示，默认不筛选

**拒答率分层折线（三条）**
- 内容：触发层①/②/③各一条周折线（如 ①12%、②5%、③3%，示例值）
- 数据来源：拒答事件（含触发层属性，PRD §4.2）
- 显示条件：始终显示

**预期区间带**
- 内容：每层预期区间的带状叠加；区间值 `[PRD 定数 · G1 后回填]`（回填前显示"区间待 G1 回填"标注，不画假区间）
- 数据来源：PRD 定数配置
- 显示条件：区间值已回填时显示带；未回填时显示待回填标注

**超区间标红标识**
- 内容：超出预期区间的层折线/数据点视觉标红 + "超预期区间"文字标识（具体视觉表现归设计系统）
- 显示条件：任一层周拒答率超出已回填的预期区间时（AC-F06-02）

**转人工率与绝对量卡**
- 内容：当月绝对量数值（如 132 单，示例值）+ 转人工率 + 周/月趋势
- 数据来源：转人工事件（PRD §4.2）
- 显示条件：始终显示

**容量预警线**
- 内容：趋势图上的水平预警线（= G1 实测月处理量 ×80%，如 240 单/月 ×80% = 192，示例值）
- 数据来源：G1 回填的 PRD 定数
- 显示条件：G1 分母已产出时显示；缺失时隐藏并显示"预警线待 G1 回填"明示（AC-F06-03）

**解决时长图卡**
- 内容：自助场景从进入会话到确认解决的周均时长（如 7.2 分钟，示例值）+ 目标 ≤10 分钟参考（引用 PRD §8.2）
- 数据来源：会话开始/会话结束事件
- 显示条件：始终显示

**满意度图卡**
- 内容：F04 会话级评分趋势（含解决确认 Yes/No 比例与可选分值；触达分型引用 PRD §8.2/§4.2）
- 数据来源：满意度评分事件
- 显示条件：始终显示；标注"趋势参考，不设达标线"

**语言分布图卡**
- 内容：来话语言占比（如 英语 91% / 其他 9%，示例值）+ "非英语 >15% 触发完整多语言评估"阈值标注（引用 PRD §8.2）
- 数据来源：会话开始事件（语言检测结果属性）
- 显示条件：始终显示

**沉默放弃率图卡**
- 内容：宽−严口径差值周趋势（如 12pp，示例值）
- 数据来源：双口径解决率聚合派生
- 显示条件：始终显示；差值持续扩大时附口径复查提示（引用 PRD §8.2）

**三指标背离提示条**
- 文案："解决率 × 满意度 × 退货趋势出现背离，请复查指标口径"（复查动作归 PRD §8.3，本页只提示）
- 显示条件：三指标背离判定触发时出现（REQ-F06-01）

**"数据回补中"标注**
- 内容：延迟数据的周/图卡级标注文案"数据回补中"
- 显示条件：客户端埋点延迟补报的数据未齐时（AC-F06-04），不静默缺数

**退货归因说明位**
- 文案："退货归因：月度手工表登记（看板化依 G4 评估）"
- 显示条件：始终显示，仅文字说明，不出图

### 5.2 辅助信息

- 数据更新时间戳 + "数据延迟 ≤24h（建议值 · 终稿前确认）"说明
- 时区口径脚注：指标窗口按 UTC 计算、看板按业务时区呈报（PRD §4.5）
- 口径出处脚注："全部指标口径见 PRD §8.1/§8.2；『高频类』= 安装/联网/配对三类，不含会员类（唯一定义 §8.1）"

## 6. 交互流程

### 6.1 页面加载与初始化

- 访问内部链接 → 浏览器口令验证（Basic Auth，建议值 · 终稿前确认）→ 验证失败 100% 拦截，无任何数据外露
- 验证通过 → 加载默认视图：周区间默认最近 12 周（DEC-004 建议值）、解决率分层默认"全部"、交互方式次维默认不筛选
- 每次访问写入访问留痕（时间/操作者/动作，蓝图 §9）

### 6.2 核心操作流程

```
进入看板（口令通过）
    │
    ├─ 有数据 → 渲染全部图卡（周粒度）
    │     │
    │     ├─ 切换 entry_source 分层 → 解决率趋势按所选层重绘；
    │     │    "未知"桶永远单列，切"固定入口/错误态入口"时不含未知流量
    │     │
    │     ├─ 切换交互方式次维 → 在当前分层内二次筛选
    │     │
    │     ├─ 调整周区间 → 全部趋势图按新区间重绘
    │     │
    │     ├─ 某触发层拒答率超区间 → 该层标红（AC-F06-02）
    │     │
    │     └─ 转人工月绝对量触预警线 → 图上标注触线；
    │          推送由系统发出（飞书机器人，无界面，本页不承载发送动作）
    │
    ├─ 部分数据延迟 → 对应周/图卡标注"数据回补中"（AC-F06-04）
    │
    ├─ G1 分母未回填 → 转人工卡降级：仅绝对量趋势 + "预警线待 G1 回填"（AC-F06-03）
    │
    └─ 完全无数据（上线首日/聚合未跑） → 空态：说明"暂无本周数据"+ 更新机制说明，不显示假数
```

### 6.3 辅助操作

- 无快捷键、无导出按钮、无写操作——只读页（回流清单导出为独立周度文件，不在本页，页面清单表 3）
- 图表数据点悬停查看具体周与数值（呈现细节归设计/前端，不改变数据口径）

## 7. 状态与边界

### 7.1 页面状态全景

| 状态 | 触发条件 | 页面表现 |
| :--- | :--- | :--- |
| 未认证态 | 无口令/口令错误访问 | 浏览器口令弹窗拦截，100% 不渲染任何数据 |
| 加载态 | 口令通过、聚合数据请求中 | 图卡占位加载，不显示假数 |
| 正常态 | 数据齐备 | 全部图卡周粒度渲染，分层/次维/周区间可切换 |
| 空态 | 上线首日或所选区间无任何数据 | "暂无本周数据"+ 数据更新机制说明（延迟建议值 ≤24h） |
| 回补态 | 客户端埋点延迟补报未齐 | 受影响周/图卡标注"数据回补中"，其余正常显示，不静默缺数（AC-F06-04） |
| 预警降级态 | G1 未产出预警线分母 | 转人工卡仅绝对量趋势 + 明示"预警线待 G1 回填"，不编造分母（AC-F06-03） |
| 标红告警态 | 任一拒答触发层超预期区间 | 该层视觉标红 + 超区间标识（AC-F06-02） |
| 背离提示态 | 解决率×满意度×退货趋势背离 | 顶部背离提示条出现，指向口径复查（动作归 PRD §8.3） |
| 请求失败态 | 聚合视图请求失败/超时 | 明确报错 + 可重试，不显示残缺数据冒充完整 |

### 7.2 边界与容错

| 边界场景 | 处理策略 |
| :--- | :--- |
| 旧版本客户端流量无 entry_source/app_version | 归"未知入口"桶**单列呈报**，不摊入固定/错误态任何分层（摊入会污染入口分层结论，REQ-F06-01/PRD §5.7） |
| 埋点上报失败（离线/杀进程） | 客户端本地暂存补报；看板对延迟数据标注"数据回补中"，不静默缺数（AC-F06-04） |
| G1 分母缺失 | 预警功能降级为绝对量趋势 + "预警线待 G1 回填"明示，不用编造分母（AC-F06-03） |
| 拒答率预期区间未回填 | 区间带不画假区间，显示"区间待 G1 回填"标注；标红逻辑在区间回填后才生效 |
| 三指标背离 | 看板给出口径复查提示；复查动作归 PRD §8.3，本页不执行复查 |
| 分层样本极小的周 | 如实呈现该周数值并可悬停看分母（呈现细节归设计），不隐藏、不平滑造假 |
| 网络异常/聚合服务不可用 | 报错 + 重试入口；不缓存展示过期数据冒充最新（数据更新时间戳始终如实） |
| 会话口径歧义（接续/重激活） | 照抄公共口径：接续排障会话不计复问、重新激活会话计为新会话（PRD §5.1/§4.2），本页不另设口径 |
| 未授权链接扩散 | 链接不公开 + 口令双重门槛；访问留痕可回溯（蓝图 §3/§9） |

## 8. 业务规则与校验

### 8.1 字段定义

> 全部字段语义引用上游唯一落点，本页不重定义。

| 字段 | 说明 |
| :--- | :--- |
| `entry_source` | 会话级入口来源，进入时刻写死：固定入口 / 错误态入口 / 未知（枚举唯一落点 PRD §4.2） |
| `interaction_mode` | 消息级交互方式：按钮组 / 自由输入 / 预置意图（与 entry_source 独立两维，R2-裁决 8） |
| `app_version` | 客户端版本，供发版线覆盖率如实呈报（PRD §7.6/§9.5） |
| 宽口径解决率 | 引用 PRD §8.2 第 1 行定义 |
| 严口径解决率 | 引用 PRD §8.2 第 2 行定义（含显式确认信号定义 §8.1） |
| 沉默放弃率 | 宽口径 − 严口径差值（PRD §8.2） |
| 拒答触发层 | ①检索相关度 / ②引用忠实 / ③硬规则（层定义 PRD §3.3） |
| 容量预警线 | G1 实测月处理量 ×80%（PRD §8.2，分母 `[PRD 定数 · G1 后回填]`） |
| 高频类 | 安装/联网/配对三类，不含会员类（唯一定义 PRD §8.1，本页所有"高频类"呈现一律用此口径） |

### 8.2 校验规则

| 校验项 | 时机 | 规则 | 失败反馈 |
| :--- | :--- | :--- | :--- |
| 访问口令 | 页面请求时 | Basic Auth（建议值 · 终稿前确认） | 浏览器标准口令拦截，不渲染数据 |
| 未知桶隔离 | 聚合呈报时 | entry_source 缺失/未知流量只入"未知"单列 | —（数据规则，违反即口径污染缺陷） |
| 超区间判定 | 周数据聚合后 | 任一触发层周拒答率 > 已回填预期区间上限 → 标红 | —（展示规则） |
| 触线判定 | 月绝对量更新时 | 月转人工绝对量 ≥ 预警线 → 图上标注 + 系统发推送 | 分母缺失时不判定，走降级明示 |
| 数据完整性 | 渲染时 | 延迟补报未齐的周必须带"数据回补中"标注 | 禁止静默缺数（AC-F06-04） |

### 8.3 特殊业务规则

- **只读铁律**：本页无任何写路径；数据面为埋点聚合视图，不直连业务表写路径（页面清单/蓝图 §7）。
- **口径引用不复制**：指标定义、目标值、枚举的唯一落点分别在 PRD §8.1/§8.2、§4.2；本页与后续实现只引用，防口径断代。
- **灰度结论两分**：呈现层保证 entry_source 分层可切换，使"引擎效果 vs 入口效果"可分离判读（PRD §8.3；错误态入口流量更难，混算会让新系统被自己的增量流量拉低）。
- **访问留痕**：每次访问记录时间/操作者/动作（轻量，蓝图 §9）。
- **推送边界**：容量预警推送载体=「建议值 飞书群机器人 · 终稿前确认」，由系统触发、无界面；本页只承载预警线可视化，产品侧只交付预警数据，容量应对为业务侧预案（REQ-F06-03/PRD §9.13）。

```
内部访问链接（不公开，无站内导航）

        ▼

        │
        ├─ 页内切换：entry_source 分层 / 交互方式次维 / 周区间
        │
        └─ 无任何页面跳转出口
（飞书容量预警推送 → 使用者自行打开本链接核查，非页面级跳转）
```

### 9.2 与其他模块的关系

- **数据上游**：App 端（PAGE-F01-01/PAGE-F03-01/PAGE-F08-01）产生的全部埋点事件（PRD §4.2 清单）经聚合视图供本页只读消费；埋点与功能同步交付是本页有数的前提（AC-F06-04）。
- **推送联动**：REQ-F06-03 触线推送（飞书机器人，无界面）与本页预警线可视化同源同分母。
- **隔离**：与 App 用户侧完全隔离——App 内无任何入口指向本页；本页不复用宿主登录态，用独立口令门槛（蓝图 §3）。
- **不含**：F05 回流清单（周度导出文件，无界面）不在本页呈现。

### 9.3 扩展预案

| 扩展方向 | 触发条件 | 改造点 |
| :--- | :--- | :--- |
