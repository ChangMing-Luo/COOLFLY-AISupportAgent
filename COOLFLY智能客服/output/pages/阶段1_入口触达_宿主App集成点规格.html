4降级行为 · AC-F08-03

错误码未结构化 → 通用进入

G2 前提不满足或上下文不可判定时，"Get help" 照常展示，点击降级为通用进入——落对话页首屏（按钮组 + 自由输入），不落纯自由输入框（U-06）。入口不消失、点击不无响应；降级项逐条列入覆盖清单呈报。

5RN 桥接注入契约 · DEC-001

宿主 → RN 容器注入字段（版本化稳定契约）

宿主打开 RN 容器时注入以下六字段（概念级清单，接口参数结构由技术方案落定）。契约只增补、不改义——它是未来全部入口形态（含阶段二语音）的接线底稿。

字段说明缺失时行为
user_credential 用户标识 / 凭证。宿主 App 登录态签发，引擎 API 校验，无独立账号体系 无凭证不进入会话（宿主登录态为前置）
device_sn 设备序列号，宿主侧当前设备上下文 显空可手补，不阻塞对话与转人工
device_model 设备型号，同上 同上
error_context 错误上下文类型，枚举：设备掉线 / 配对失败（含卡死） / 扫码失败 / 不可判定；仅错误态入口进入时非空 不可判定或缺失 → 通用进入，落首屏
entry_source 枚举：固定入口 / 错误态入口；埋点侧另有"未知"桶承接旧版本缺失流量 缺失归"未知"桶，看板分层单列
app_version 客户端版本，供发版线覆盖率按版本如实呈报 缺失随 entry_source 同归未知桶口径
只增补、不改义（S-06） 凭证不走 URL 明文 / 不落不安全存储（S-01） 引擎 API 逐次校验凭证（S-02） 无任何密码字段 / 不注入运行日志（S-03） 卡片 UI 与文案随 EAS Update 热更；仅原生入口三样随 App 版本爬坡
6push 深链接线 · DEC-002

仅 F03 目标态：客服回复写回同一会话流并触达 push；本规格只负责"点击通知 → 正确落回对话页"的宿主侧接线。push 权限请求时机与被拒文案属 PAGE-F03-01 / PAGE-F01-01 范围。

7边界与呈报要点

入口在任何降级场景下不消失、点击有响应

离线态 App 全局网络异常时入口仍展示，点击进入对话页离线提示态；不出现按钮消失或点击无响应（F-05）。
旧版本态 存量固定入口保全引擎线全能力；卡片 UI 缺失时排障以纯文本分步引导，每条消息一步 + 文字确认，路径完整不缺分支（AC-F08-04）。
覆盖率呈报 发版线覆盖率随升级率爬坡、按 app_version 如实呈报，不并入引擎线 2 周灰度承诺；entry_source 缺失流量归"未知"桶单列（REQ-F08-03）。
灰度不暴露分组 灰度桶内外入口与 UI 照常、文案两版一致，桶外对话走存量引擎，不因界面差异暴露分组（U-05）。
