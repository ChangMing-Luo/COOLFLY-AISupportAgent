## 变体开关（原型 `data-props`）

| prop | 取值 | 默认 | 说明 |
|---|---|---|---|
| `navMode` | sidebar / topmodule | sidebar | 左侧栏 or 顶部模块栏 + 二级横导航 |
| `density` | comfortable / compact | comfortable | 表格行距 11px/5px、主区留白 26px/16px、字号 14/13 |
| `reviewMode` | drawer / fullpage | drawer | 审核走右侧抽屉 or 独立全页 |
| `showAiAssist` | true / false | true | 编辑器 AI 助手卡显隐 |
| `startRole` | super / ops | super | 起始角色：陈默（超级管理员）/ 林静（知识运营） |
