## 1. 完成定义

同时满足以下条件才算完成：

1. 安装、构建、启动与全部冒烟验收通过。
2. 本文件 §2–§5 的每一条验收行都通过，没有跳过、弱化或删除。
3. PRD/bugfix 中本期 required Source IDs 均被验收行覆盖。
4. Design 中全部 MVP 页面、弹窗、关键状态与交互均已落地；每页只对 HTML 明确呈现的状态完成同内容区尺寸的原型/成品截图对照，HTML 未呈现的状态以行为证据验收。
5. 最终提供 fresh verification evidence：实际命令、退出码、测试结果和截图对；不能用“应该通过”或“UI 自动化已过”代替视觉验收。
