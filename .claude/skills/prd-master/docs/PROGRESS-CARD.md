# 行动卡 / 进度卡格式规范

## 为什么需要

行动卡让企业家随时知道：
- 现在到哪一步了？
- 还有多远？
- 接下来该做什么？

只在真正发生进度变化或用户主动询问时展示，避免打断当前问题。

## 什么时候展示完整行动卡

只在以下时机展示完整“📍 行动卡”：

- 启动新流程或恢复上次流程；
- 阶段切换；
- 用户要求暂停；
- 最终完成；
- 用户主动询问进度。

阶段 1 的普通访谈轮次**不追加完整行动卡**；当前前沿的问题必须是该轮最后内容，问完就等待回答。没有阶段变化时也不要重复同一张卡，以免进度信息淹没问题。

需要展示时使用以下格式：

格式：

```
---
📍 **当前进度**：阶段 X.Y · {阶段名}（已完成 N/7 阶段）

⏱ **本阶段还需**：{能可靠判断时给区间；阶段 1 未决分支未扫描完时写“取决于剩余关键分支，不承诺固定轮数”}

👉 **你现在需要做的**：
{一句话告诉企业家此刻该做什么——回答当前问题 / 看一个文件 / 拍板一个选择}

🔮 **接下来会发生什么**（让企业家有预期）：
1. {下一步}
2. {再下一步}
```

## 7 阶段的预估时间和轮数（基准）

| 阶段 | 预估时间 | 轮数 |
|------|---------|------|
| 0 自由倾诉 | 1-3 分钟 | 1 轮 |
| 1 苏格拉底深挖 | 取决于复杂度 | 无固定上限；简单项目数轮，复杂项目可几十轮 |
| 2 价值论证 | 3-10 分钟 | 逐项确认价值假设 |
| 3 自动调研 | 5-15 分钟 | 1 轮（系统自动跑） |
| 4 V0+辩论 | 15-30 分钟 | 3 轮博弈 + 用户拍板 |
| 5 PRD 协同写作 | 20-40 分钟 | 系统自动跑 |
| 6 方案 PPT | 5-15 分钟 | 系统自动跑 |
| **总计** | **取决于阶段 1 深挖与方案争议** | **不设总轮数承诺** |

## 示例

### 阶段 0 结束

```
（这里是 Lead PM 的回放）

---
📍 **当前进度**：阶段 0.1 · 自由倾诉回放（已完成 1/7 阶段）

⏱ **本阶段还需**：< 1 分钟（你确认理解对不对）

👉 **你现在需要做的**：
看上面"我听到的是这样"，告诉我对不对、要补充啥

🔮 **接下来会发生什么**：
1. 进入阶段 1 苏格拉底深挖，每轮询问当前可独立回答的完整前沿，依赖项留到后续
2. 直到阻塞产品方向的关键分支全部问清；简单项目数轮，复杂项目可能几十轮
3. 然后论证价值、调研、出方案、吵架、写 PRD、生成方案 PPT
```

⏱ **本阶段还需**：你拍板 1 次（< 5 分钟）

## 行动卡 ≠ 详细日志

行动卡是给企业家看的**阶段导航**，不是每轮重复的日志。

❌ 不要写"系统已经处理了 5 个 SKU 的销量数据..."
✅ 写"我已经把 200 SKU 的销量趋势画好，你拍板要不要继续调研物流"

## 行动卡的"主动感"原则

需要展示的每张行动卡都要回答企业家潜意识的 3 个问题：

1. **"我现在在哪？"** → 当前进度
2. **"还要多久？"** → 本阶段还需
3. **"我该干啥？"** → 你现在需要做的

光有 1+3 是"咨询顾问汇报"，加上 2 才是"主动 lead 你"。
